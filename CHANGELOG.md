# Changelog

## 1.8.0 (21 Oct 2026)
- Admin tab: Remove user (permanent). Past entries and activity stay under the person's username; you cannot remove yourself or the last active administrator.

## 1.7.1 (21 Oct 2026)
- Every checklist item is rated Good / Average / Bad. The six former Yes/No items no longer show Yes/No; older Yes/No answers still score the same and display as the matching band.

## 1.7.0 (21 Oct 2026)
- Version number shown on the sign-in screen, in the header and in the Admin tab.
- Android/PWA manifest: app id, shortcuts (Log a check, Dashboard, Reports), portrait orientation.

## 1.6.0 (21 Oct 2026)
- Phone / installed-app layout: bottom tab bar, compact Victory Farms header, larger touch controls.
- Victory Farms logo as the app icon and on the sign-in screen.

## 1.5.0 (21 Oct 2026)
- Dashboard graphs in Victory Farms colours.
- Report graphs and slides follow the Victory Farms PPT template, with a cover slide.
- Fixes: Yes/No rating list mismatch; low-memory photo upload on phones; faster loading.

## 1.4.0
- Admin: clear data for a period (with backup CSV). Export CSV by date range and location.

## 1.0.0 - 1.3.0
- Web app (installable), sign-in with roles, activity log, Excel import, reports.
